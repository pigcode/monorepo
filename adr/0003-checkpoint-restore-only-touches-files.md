# 恢复 checkpoint 只恢复文件，不回滚对话

架构文档要求：Agent 不支持原生回滚时，恢复 checkpoint 要在修改任何文件前拒绝。但 Claude Code 和 Codex 的 `rollback` 功能现在都是 `false`，照这样做，恢复功能对所有 Agent 都不能用。我们决定：恢复只把工作区文件改回去，对话和 Agent 会话都不动；确认时明确告诉用户对话不会回滚，Agent 也不会知道文件变了。这一条取代架构文档第 315–317 行和 M3 验收里「改文件前拒绝」的要求。

## Considered Options

- 等 Agent 支持原生回滚再开放恢复：在此之前，用户改坏工作区时没有办法退回去。文件能恢复比对话能回滚更常用。
- 恢复文件，同时给会话发一条消息让模型知情：消息会进入对话和模型上下文，用户没有发过它；模型也可能据此继续行动。以后真有需要再单独做。

## Consequences

- 恢复后模型记得的文件内容可能和磁盘不一致，要靠模型重新读文件或用户说明。
- `rollback` 这项 Agent 功能暂时没有代码读取它。以后某个 Agent 支持原生回滚时，再决定恢复是否同时回滚它的会话。
- 架构文档第 318 行要求确认时显示受影响的文件，现在还没做，和这个决定无关，单独跟进。
