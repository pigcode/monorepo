# 磨砂效果默认关闭，v1.0 不接通

外观设置里早就有 `glass`（磨砂透明度，0–100）这个值和整套半透明配色，但没有任何代码把 `data-glass` 写到页面上，设置页也没有控件，所以它在应用里从来不生效。决定：v1.0 就当它是关闭的，不接控件、不接窗口材质，也不为它生成视觉基线。

## Considered Options

- 接通磨砂：要新增设置控件、决定默认值、处理 Linux 没有系统磨砂的情况，还要在关闭时把窗口的 vibrancy/mica 一起收掉。这些都不影响 v1.0 的主要目标。
- 删掉现有样式和 `glass` 取值：`tokens.css` 里的两套配色和 `glass.css` 有测试覆盖，删掉会牵动主题解析；留着不用是更小的代价。

## Consequences

- 窗口仍然带系统的磨砂材质（macOS vibrancy、Windows mica），但界面本身始终是不透明配色，两者叠加的效果就是现在这样。
- `appearance-settings.ts` 里的 `glass` 是一个没人读的配置项，将来接通时它就是现成的起点。
- 想做磨砂时按 #54 重新决策，不要直接开始写控件。
