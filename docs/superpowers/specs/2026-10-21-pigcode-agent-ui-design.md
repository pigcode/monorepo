# Pigcode Agent UI Design

**Date:** 2026-10-21
**Status:** Supersedes the visual direction of `2026-10-21-pigcode-ui-refinement-design.md`; layout, keyboard map and accessibility rules from that spec still apply.
**Reference:** Cursor's Agent panel and Agents window — flat, dense, almost monochrome, borders instead of shadows, colour only for status, links/focus and diff.

## Principles

- **平面**：不透明表面、1px 细线、4–10px 圆角；没有渐变、毛玻璃、发光和大面积彩色按钮。
- **安静**：界面文字 12–13px，正文 13.5px；默认状态不说话（空闲不显示、完成的步骤不写“已完成”），只有运行中、等待许可、失败会出声。
- **文本即界面**：助手回复直接落在时间线上，没有头像和气泡；工具调用是一行“动词 + 对象”，而不是一张张卡片。
- **三栏**：左侧会话列表、中间对话、右侧审阅面板（文件 / Diff / 终端 / 检查点 / PR / 预览）。

## Tokens

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| `--bg-main` | 99.3% | 18.6% | 对话区、右栏 |
| `--bg-side` | 96.4% | 15.6% | 侧栏 |
| `--surface-2` | 97.4% | 22% | 用户消息、命令卡、代码块、展开后的步骤 |
| `--line` / `--line-strong` | 10% / 16% 黑 | 9% / 15% 白 | 所有分隔线与描边 |
| `--accent` | 蓝 | 蓝 | 焦点环、运行中的图标、链接 |

圆角：控件 6、卡片 8、输入框 10。阴影只用于浮层（命令面板、回到最新）。

## Sidebar · 会话列表

- 260px，右侧 1px 线。品牌行只放小标记、名字和搜索图标。
- 「新会话」是描边的中性按钮（28px，`+` 图标，右侧 ⌘N），下面一行是搜索入口（⌘K）。
- 项目作为分组头：展开箭头、名字、会话数；悬停出现「+」在该项目新建。
- 会话行两段：第一行状态图形 + 标题；第二行 11px 的「来源 · 时间」。状态图形：运行中旋转、完成打勾、失败叉、等待许可琥珀点脉冲、排队蓝点。活动行用 `--active` 背景，没有彩色竖条。

## Center · 对话

- Tab 栏 36px：每个 tab 是 26px 的小块（状态点 + 标题 + 悬停可见的 ×），活动 tab 用 `--active`；溢出一侧渐隐，`+` 固定在滚动区外。
- 线程头 36px：标题 + 项目名在同一行；右侧是状态（运行中带旋转图标、等待许可是琥珀小块、空闲不显示）、provider / 模型下拉、工作台与环境按钮。
- 用户消息：整行卡片（`--surface-2` + 1px 线，8px 圆角），悬停可复制。
- 助手消息：正文直接渲染（段落、标题、列表、加粗、行内代码、围栏代码块）；来源与时间是悬停才出现的 11px 脚注。
- 工具步骤：26px 一行，`图标 动词 对象 …… 耗时`，动词灰、对象用等宽，运行中整行变亮并带旋转图标，失败红字。点击展开成一张 `--surface-2` 卡片显示输入 / 输出。连续步骤间距 3px。
- 命令步骤（Bash / shell）：独立卡片，`$ 命令` 等宽，右侧耗时与状态，展开显示输出；失败时描边偏红。
- 子代理：同一种步骤行，展开后内部事件沿 1px 竖线缩进。
- 计划：`执行计划 1/3` 卡片，完成的步骤变灰。改动：`N 个文件已更改 +a −b`，每个文件一行带各自的增删数。
- 审批：左侧 2px 琥珀线的卡片，eyebrow「需要许可」+ 问题 + 说明 + 命令块，按钮「允许一次」（实心）、「本会话内允许」、「拒绝」。已处理后只剩一行「✓ 已允许一次 · 问题」。
- 运行中但没有文字输出时，时间线末尾一行「⟳ 正在生成…」；流式输出时光标贴在最后一行末尾。
- 空状态：单色标记、一句话、两枚快捷键。

## Composer

- `--surface` + 1px `--line-strong`，10px 圆角，聚焦时描边变成 `--accent`。
- 顶部一行「@ 添加上下文」小块；正文 13.5px；底部工具栏左侧是「权限模式 ▾」（图标随模式：询问 ✋、自动 ∞、计划 ☰）、「模型 ▾」、「思考 ▾」，右侧是 26px 的实心圆形发送按钮（↑），运行中换成方块停止按钮，悬停变红。不再显示 ⌘↵ 文案，放在按钮 tooltip 里。

## Right · 审阅面板

- 头部 36px「工作台」+ 关闭；tab 行 32px 文字 tab，活动项底部 1px 前景色线。
- 面板内容平铺：文件树 24px 行、Diff 基准行、检查点卡片、PR 卡片与表单、预览表单；空状态是「图标 + 一句话 + 一个动作」。

## Out of scope

- 标签页拖拽排序、按时间分组的侧栏、主题切换按钮、i18n 清理（`RightPanel` / `CheckpointPanel` 仍有硬编码中文）。
