# Pigcode Agent UI Design

**Date:** 2026-10-21
**Status:** Supersedes the visual direction of `2026-10-21-pigcode-ui-refinement-design.md`; layout, keyboard map and accessibility rules from that spec still apply.
**Reference:** Cursor's Agents window — one flat light-gray surface, white input and cards, a darker gray block for the user's prompt, compact single-line lists, colour only for status, links and diff.

## Principles

- **一块平面**：侧栏、对话区、右栏同一种浅灰；只有输入框、改动卡片、代码块和右栏内容是白色；用户消息是深一点的灰块。1px 细线、6/10px 圆角；没有渐变、毛玻璃、发光和彩色大按钮。
- **安静**：界面文字 12–13px，正文 13.5px；空闲不显示状态，完成的步骤不写「已完成」，只有运行中、等待许可、失败会出声。
- **文本即界面**：助手回复直接落在时间线上，没有头像和气泡；工具调用是一行「动词 + 对象」。
- **三栏**：左侧导航与会话列表、中间对话、右侧审阅面板。

## Tokens

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| `--bg-main` / `--bg-side` | 97.6% | 17.8% | 整窗底色 |
| `--surface` | 白 | 22% | 输入框、改动卡、代码块、右栏内容卡 |
| `--surface-2` | 93.4% | 24% | 用户消息、行内代码、展开后的输出 |
| `--line` / `--line-strong` | 9% / 15% 黑 | 9% / 15% 白 | 分隔线与描边 |
| `--active` | 既有 | 既有 | 选中的 pill、侧栏活动行 |

## Sidebar

- 256px，右侧 1px 线。顶部 40px 拖动区，右端一个搜索图标（⌘K）。
- 导航行（26px，图标 + 文字）：新会话、定时任务、插件；没有活动会话时「新会话」高亮。
- 「项目」小标题（右侧有添加项目图标），下面一行「+ 添加项目」，再往下每个项目是「文件夹图标 + 名字」的分组头，悬停出现「+」在该项目新建。
- 会话行 26px：6px 状态点（空闲灰、运行中蓝色脉冲、排队蓝、等待许可琥珀脉冲、完成绿、失败红）+ 标题 + 右侧短时间（2m / 3h / 5d）。活动行 `--active`。
- 底部 44px：小头像 + Pigcode + 齿轮（设置 ⌘,）。

## Center

- 顶栏 40px，没有底线：左侧是会话 pill（活动的用 `--active`，带状态点与悬停可见的 ×，溢出时渐隐，`+` 固定在外），右侧是工作台与环境两个图标。
- 对话列 720px：
  - 用户消息：整行灰块（`--surface-2`，10px 圆角，无边框），悬停可复制。
  - 助手消息：正文直接渲染（段落、标题、列表、加粗、行内代码、围栏代码块）；下方一行始终可见的「复制 · 2 分钟前」。
  - 工具步骤：26px 一行「图标 动词 对象 …… 耗时」，运行中整行变亮，失败红字；点击展开成白色卡片显示输入 / 输出。连续步骤间距 3px。
  - 命令步骤：白色卡片，`$ 命令` 等宽，展开显示输出，失败时描边偏红。
  - 子代理：同一种步骤行，展开后内部事件沿竖线缩进。
  - 计划：`执行计划 1/3` 卡片。改动：「N 个文件已更改 +a −b」卡片，列出文件（名字 + 目录 + 各自增删数），多于 4 个折叠成「显示更多 (n)」，「查看」展开 diff。
  - 审批：左侧 2px 琥珀线的白卡，eyebrow「需要许可」+ 问题 + 说明 + 命令块；按钮「允许一次」（实心）、「本会话内允许」、「拒绝」。处理后只剩一行。
  - 运行中无文字时末尾一行「⟳ 正在生成…」；流式输出时光标贴在行尾。
- 空会话：输入框竖直居中；选项行放在输入框上方，两枚快捷键提示在下方；没有会话时多一行说明。

## Composer

- 白卡，10px 圆角，1px `--line` + 很轻的投影；聚焦只把描边加深，不用蓝色。
- 卡内：正文 13.5px；底部左侧一个 24px 圆形「+」（附件），右侧「模型 ▾」文字和 24px 实心圆形发送按钮（↑），运行中换成方块停止、悬停变红。
- 卡外一行（空会话在上、进行中在下）：「📁 项目」「provider ▾」「权限模式 ▾」（图标随模式：✋ / ∞ / ☰）「思考 ▾」，右端是运行状态（⟳ 运行中 / ● 等待许可）。

## Right

- 顶部 40px 一行 pill tab：文件 / Diff / 终端 / 检查点 / PR / 预览，活动项 `--active`；右端 ×。
- 内容放在一张白卡里（1px 线，10px 圆角）：文件树、Diff 基准行、检查点卡片、PR 卡片与表单、预览表单；空状态是「图标 + 一句话 + 一个动作」。

## Out of scope

- tab 拖拽排序、按时间分组的侧栏、主题切换按钮、i18n 清理（`RightPanel` / `CheckpointPanel` 仍有硬编码中文）。
